Controller fault-confinement states
Read these thresholds when explaining the demonstration.
ERROR ACTIVETEC < 128 and REC < 128. The node participates normally in the simulated network.
ERROR PASSIVETEC ≥ 128 or REC ≥ 128. The controller remains able to communicate, but is in a degraded error-confinement state.
BUS-OFFTEC reaches 256. The node is prevented from transmitting until recovery completes.
Recovery model limitation: The simulation counts 128 eligible 11-recessive-bit idle-sequence observations, one per 100 ms virtual scheduler cycle. This makes recovery progress visible and testable; it is a discrete educational approximation, not a physical bit-timing or electrical CAN bus model.
